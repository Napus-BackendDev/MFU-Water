# แบบ UI สีสำหรับพัฒนาต่อ

ออกแบบวันที่ 15 ตุลาคม 2026 ในไฟล์ Figma เดิม โดยใช้ UI และ clipboard ปกติ ไม่ใช้ Figma Plugin หรือ Figma connector งานเดิม 24 wireframes ยังคงอยู่ ชุดใหม่อยู่ข้างกันในหน้า `Wireframes R01–R29` ภายใต้กรอบ `Production UI · 32 Screens · Desktop + Mobile · Farmers`.

Figma: https://www.figma.com/design/ugwtJeQWlkDFjkStU45luV/design-mfu-water-flow?node-id=16-2222

## จุดมุ่งหมาย

หน้าจอ Operate สำหรับชาวนาที่ไม่ถนัดเทคโนโลยี ใช้พื้นอุ่น เขียวเข้ม ตัวหนังสือไทยอ่านง่าย และปุ่มหลักใหญ่ ผู้ใช้ทำสามงานหลัก: ดูผลน้ำ บันทึกผล และขอความช่วยเหลือ แยกงานตรวจข้อมูล รายงาน และการติดตามไว้ในส่วนทีมงาน ชื่อแสดง “น้ำกก ใกล้บ้าน” เป็นข้อเสนอในแบบ ไม่ใช่ชื่อแบรนด์ที่ผู้ใช้ยืนยันใหม่

Desktop ใช้เมนู ดูผลน้ำ / บันทึกผล / เรียนรู้ และปุ่มช่วยเหลือในเนื้อหา Mobile ใช้แถบล่าง ดูผลน้ำ / บันทึกผล / ช่วยเหลือ หน้าจอมือถือจัดโครงสร้างใหม่ตามพื้นที่ ไม่ใช่ย่อ Desktop การกรอกเป็นหน้าเดียวตาม requirement; หน้ายาวแสดงเนื้อหาต่อเนื่องและส่วนล่างในแบบ ไม่ได้ยืนยันพฤติกรรม sticky/scroll ของระบบจริง

## สีและขนาด

ค่าที่ใช้จริงอยู่ใน `production-tokens.json` ใช้ Noto Sans Thai เป็นหลัก ใน Figma ตรวจพบ native Text / Typography เป็น Noto Sans Thai ข้อความและเวกเตอร์แก้ไขได้ ไม่ใช่ภาพแบน

หัวเรื่อง Desktop 36px / Mobile 30px เนื้อหาหลัก 18–22px ปุ่มหลักส่วนใหญ่สูง 60–68px ปุ่มรองขนาดเล็กมี 48–58px ฟิลด์สูง 60px ระยะขอบ Desktop 48px / Mobile 24px ขนาดแบบ Desktop 1440px และ Mobile 430px ความสูงเปลี่ยนตามเนื้อหา

ตรวจ contrast 5 คู่: ink/bg 10.58:1, muted/white 6.16:1, white/green 8.58:1, amber/pale 5.58:1, red/rose 6.01:1 ไม่ใช่การรับรอง accessibility ครบทุกองค์ประกอบ ต้องตรวจการใช้จริงกลางแจ้ง การอ่าน การแตะ โฟกัสแป้นพิมพ์ และ usability กับกลุ่มผู้ใช้จริงต่อ

## ข้อมูลจำลองและการตีความ

- ทุกหน้าติดป้ายข้อมูลตัวอย่าง ไม่มีผลภาคสนาม ข้อมูลรายบุคคล พิกัดบ้าน หรือเบอร์จริง
- DEMO-001: สารหนู 5ppb เก็บ 15 ต.ค. 2569 เวลา 08:30 ส่ง 08:42 เผยแพร่แล้ว
- DEMO-002: สารหนู 100ppb เก็บ 09:00 ส่ง 09:10 รอตรวจ ค่าและภาพไม่ออกหน้าสาธารณะ
- กราฟ Mock วันที่ 12–15 ต.ค. ใช้ `[30, 10, 5, 5]`ppb คำนวณบนแกนตัวเลข 0–50; ชนิดน้ำและวิธีเดียวกัน
- ค่าชุดทดสอบ 0/5/10/30/50/100/200/300/500ppb ค่า >50 ส่งทานตาม POC ไม่ใช่เกณฑ์รับรองว่าน้ำปลอดภัย
- หมุดผลน้ำเป็นข้าวหลามตัด จุดชุมชนเป็นวงกลม มี legend ไม่ใช้สีอย่างเดียว
- แผนที่เป็นรูปทรงจำลอง ไม่มี CRS หรือพิกัดภาคสนาม ไม่ใช่ภาพดาวเทียมหรือเส้นอพยพ
- ภาพ คลิป ตรา และแหล่งทางการยังรอไฟล์และสิทธิ์ยืนยัน ไม่สร้างคำกล่าวอ้างหรือภาพจริงแทนต้นทาง

## หลักฐานและข้อจำกัด

ตรวจจำนวน 32 บอร์ด / 29 รหัสและ contrast ใน `production-checks.json` ตรวจขอบข้อความของ SVG ทั้ง 32 บอร์ดจาก DOM ที่แสดงจริงไม่พบล้นขอบ canvas ไม่เท่ากับตรวจ overlap ภายในทุกกล่อง ภาพ Figma ที่ตรวจรวม Desktop หลัก Mobile หลัก/รายละเอียด/ฟอร์ม และแผนที่ทีม

ผู้รีวิวแยกตรวจและให้ ship เฉพาะรายการแก้: สเกลกราฟ ชื่อสารใกล้ค่า รูปหมุดตาม R23 และ legend ที่ไม่ทับคำอธิบาย ไม่ใช่การรับรองทุกหน้าหรือทุก requirement ใหม่

ชุดนี้เป็น static high-fidelity UI สำหรับส่งต่อพัฒนา ยังไม่มี prototype connections, responsive runtime, GPS, auth, backend, การบังคับสิทธิ์, persistence, PDF A0 ที่ตรวจจริง หรือการส่งข้อความ ไม่มีการแก้แอป ฐานข้อมูล หรือ deploy จากงานรอบนี้

สร้างไฟล์ซ้ำ: `python docs/wireframes/build_production.py` ผลลัพธ์คือ `kok-water-production.svg`, `production-screens.json`, `production-coverage.json`, `production-checks.json` ส่วน `production-tokens.json` และเอกสารนี้เป็น handoff ที่ดูแลแยกจากตัวสร้าง
