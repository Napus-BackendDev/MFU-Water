# ข้อมูลอพยพบน production

ข้อมูลบ้านกลุ่มเปราะบางและเส้นอพยพไม่อยู่ใน GitHub หรือ public bundle ใช้ API `GET /api/evacuation/restricted` ที่ตรวจรหัส Bearer ก่อนส่งข้อมูล ห้ามเปลี่ยนเป็น endpoint สาธารณะ

## เตรียมข้อมูล

รันบนเครื่องที่มีข้อมูลต้นฉบับ:

```powershell
node scripts/prepare-evacuation-deploy.mjs
```

สคริปต์สร้างโฟลเดอร์ใหม่ใต้ `%LOCALAPPDATA%/MFUKokWaterWatch/restricted/deployment/` โดยไม่แก้ข้อมูลต้นฉบับ ภายในมี:

- `EVACUATION_DATA_JSON.txt`: ข้อมูลพิกัดและเส้นทางที่ตัดชื่อ/ข้อมูลประกอบออกแล้ว
- `EVACUATION_ACCESS_KEY_SHA256.txt`: hash ของรหัสเข้าถึง
- `access-key.txt`: รหัสเข้าถึงแบบสุ่ม 256 บิต ให้เฉพาะผู้ได้รับสิทธิ์ ห้าม commit หรือส่งในแชตสาธารณะ

## ตั้งค่า deployment

เพิ่ม Environment Variables แบบ server-only ใน Vercel Project ของเว็บนี้ แล้ว deploy โค้ดรุ่นใหม่:

| ชื่อ | ค่า |
| --- | --- |
| `EVACUATION_DATA_JSON` | เนื้อหาไฟล์ชื่อเดียวกัน `.txt` ทั้งหมด แบบ JSON บรรทัดเดียว |
| `EVACUATION_ACCESS_KEY_SHA256` | เนื้อหาไฟล์ hash `.txt` |

อย่าใช้ prefix `VITE_` หรือ `NUXT_PUBLIC_` และอย่าเพิ่มตัวรหัสจริงเป็นตัวแปรสาธารณะ ต้องตั้งค่าใน environment ที่ deploy จริง เช่น Production หรือ Preview หากใช้ Preview เพื่อทดสอบ ให้เลือก environment นั้นด้วย

## ใช้งาน

เลือกท่าตอน → อพยพกลุ่มเปราะบาง → เปิดข้อมูลกลุ่มเปราะบาง → กรอกรหัสที่ผู้ดูแลให้ เว็บจะโหลดหมุดและเส้นทางจาก API หลังผ่านการตรวจรหัสเท่านั้น กด “ปิดข้อมูลจำกัดสิทธิ์” เพื่อเอาข้อมูลออกจากหน้า หรือโหลดหน้าใหม่เพื่อกลับสู่สถานะปิด

รหัสไม่ถูกบันทึกใน localStorage, URL หรือ cookie ข้อมูลอยู่ในหน่วยความจำของหน้าเว็บเท่านั้น Response ใช้ `Cache-Control: private, no-store` และ `Vary: Authorization` ผู้ที่ได้รับสิทธิ์ยังสามารถบันทึกหรือคัดลอกข้อมูลที่เปิดดูได้ จึงต้องแจกจ่ายรหัสอย่างจำกัด รหัสนี้เป็นสิทธิ์ร่วมสำหรับทีม ยังไม่ใช่บัญชีแยกรายบุคคลหรือ audit log

การเปลี่ยน hash และ redeploy จะยกเลิกรหัสเดิมสำหรับคำขอใหม่ แต่ไม่เรียกคืนข้อมูลที่ผู้ใช้เคยโหลดแล้ว ต้องส่งรหัสใหม่ให้ผู้ได้รับสิทธิ์ด้วย โหมดพัฒนาในเครื่องยังใช้ endpoint loopback เดิมได้ตามเดิม

## ตรวจรับ

- ไม่มีรหัส/รหัสผิด: HTTP 401 และไม่มีพิกัด
- ยังไม่ตั้งค่าหรือข้อมูลผิด: HTTP 503 ไม่มีข้อมูลหรือรายละเอียด path หลุดออกมา
- รหัสถูก: เฉพาะพิกัด ประเภทหมุด รหัสลำดับ และเส้นทาง ไม่มีชื่อหรือข้อมูลครัวเรือนอื่น
- หมุดและเส้นอพยพอยู่เหนือสีจำลองน้ำท่วม เปลี่ยนระดับน้ำได้ตามเดิม
- พิกัดยังเป็นการเทียบจากแผนต้นฉบับ ไม่ใช่ข้อมูลสำรวจยืนยันภาคสนามหรือการรับรองความปลอดภัยเส้นทาง
