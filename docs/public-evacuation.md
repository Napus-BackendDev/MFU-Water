# ข้อมูลแผนอพยพสาธารณะ

ผู้ใช้ยืนยันให้ผู้เข้าชมเว็บทุกคนเห็นหมุดบ้านกลุ่มเปราะบาง 67 จุดและเส้นอพยพ 1 เส้น โดยไม่ต้องกรอกรหัส วันที่ 21 ตุลาคม 2026

เว็บโหลด `/evacuation/thaton.json` จาก `public/evacuation/thaton.json` ทั้งโหมดพัฒนาและ production ไม่ต้องตั้ง environment variables หรือฐานข้อมูลสำหรับชั้นข้อมูลนี้ ช่องรหัสและ restricted API รุ่นก่อนถูกถอดออกแล้ว

ข้อมูลที่เผยแพร่มีเฉพาะรหัสลำดับใหม่ ประเภทหมุด พิกัด และเส้นทาง ไม่มีชื่อ ข้อมูลติดต่อ รหัสครัวเรือนต้นทางหรือรายละเอียดอื่น อย่างไรก็ตาม พิกัดกับประเภทหมุดเป็นข้อมูลสาธารณะที่ผู้ชมดาวน์โหลดได้ตามขอบเขตที่ผู้ใช้ยืนยัน

ต้นทางคือ `SWG5_ThaTon_Vulnerable_Populations_Evacuation_Map.pdf` เทียบภาพและปรับแนวเส้นกับถนน OpenStreetMap ตำแหน่งยังเป็นค่าประมาณ ไม่ใช่การรับรองความปลอดภัยของเส้นทาง ดู source metadata ใน JSON

เมื่อต้องสร้างไฟล์ใหม่จากข้อมูลต้นฉบับในเครื่อง:

```powershell
node scripts/publish-evacuation.mjs
```

สคริปต์อ่าน `%LOCALAPPDATA%/MFUKokWaterWatch/restricted/evacuation-review.json` คัดเฉพาะฟิลด์ที่อนุญาตและเขียนไฟล์สาธารณะ ไม่แก้หรือลบข้อมูลต้นทาง การ clone และรันเว็บใช้ไฟล์ที่สร้างแล้ว จึงไม่ต้องมีข้อมูลต้นฉบับในเครื่องใหม่

หากเคยตั้ง `EVACUATION_DATA_JSON` หรือ `EVACUATION_ACCESS_KEY_SHA256` บน Vercel ไว้ รุ่นนี้ไม่ใช้ตัวแปรดังกล่าวแล้ว ข้อมูล MyMaps อื่นยังคงเป็นข้อมูลจำกัดสิทธิ์ตามเดิม
